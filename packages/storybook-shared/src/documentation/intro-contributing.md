## Bijdragen

De broncode staat op <https://github.com/nl-design-system/tilburg>. Issues en PR's voor nieuwe componenten, bug-fixes en
documentatie zijn welkom. Hoe je de repository opzet, test en een component in alle lagen toevoegt, staat in
[`CONTRIBUTING.md`](https://github.com/nl-design-system/tilburg/blob/main/CONTRIBUTING.md). De belangrijkste afspraak:
de HTML/CSS-referentie is leidend, en React, Angular en Web Components renderen precies dezelfde DOM en classes.

# Tilburg Angular componenten

Deze Storybook documenteert `@gemeente-tilburg/components-angular` — de Angular-laag van de Tilburg-componentenbibliotheek. Hij bevat zowel de **Angular-componenten** (`Tilburg Angular/…`) als de **HTML/CSS-referentie** (`Tilburg HTML/…`) zodat je beide naast elkaar kunt vergelijken zonder van Storybook te wisselen. Elke Angular-story onder `Tilburg Angular/…` documenteert de beschikbare `@Input`s en `@Output`s in de **Usage**-sectie van zijn auto-docs-pagina.

Er bestaat **een tweede, onafhankelijke Storybook** met de React-componenten (`Tilburg React/…`), de Web Components (`Tilburg Web Components/…`) en dezelfde HTML/CSS-referentie. De twee zijn niet aan elkaar gekoppeld — start de andere Storybook apart als je beide framework-lagen wilt zien.

Componenten met het label **TLB** introduceert Tilburg zelf; ze zijn niet gebaseerd op een Utrecht-component (zie
_Tilburg en NL Design System_ hieronder). Met de knop **Alle componenten** in de toolbar filter je de zijbalk op
**Alleen TLB** of **Zonder TLB**.

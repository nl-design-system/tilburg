Bedoeld voor propriëtaire fontbestanden. **Het package is nu nog leeg:** de Tilburg-fonts (TradeGothicCondensed18 en
Roboto) worden in de Storybooks via een webfont-kit geladen (`packages/storybook/config/preview-head.html`). Zie
"Aan de slag" in de Storybook voor hoe je de fonts in je eigen project laadt, en `NOTICE.md` voor de licentie.
